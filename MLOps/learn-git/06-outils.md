# 6. Bonus : outils graphiques

Tu peux utiliser Git sans ligne de commande.

| Outil | Type | Points forts | Pour qui |
|-------|------|--------------|----------|
| **GitHub Desktop** | Application | Très simple, parfait pour débuter (GitHub) | Débutant |
| **GitLens** | Extension VS Code | Historique et auteur de chaque ligne, visualisation des branches | Tu codes déjà dans VS Code |
| **Sourcetree** | Application | Graphe visuel complet, multi-plateformes (GitHub, GitLab…) | Intermédiaire |

> Conseil : apprends d'abord les commandes de [02-commandes-de-base.md](02-commandes-de-base.md), les outils graphiques ne font que les illustrer.
